# Alien Forest Adventure
A browser-playable real-time 3D third-person sci-fi adventure built with Three.js.

## Play online
The game is intended to be hosted as a Render Static Site from this directory.

## Controls
- WASD / arrow keys: move
- Mouse: look around
- Shift: sprint (uses suit energy)
- Space: jump
- Esc: release mouse
- R: restart

## Mission
Collect five glowing crystals, avoid the alien sentinels, and reach the portal.

## Tech
- Three.js 0.164.1 via CDN
- WebGL renderer with fog, shadows, dynamic lighting, 3D forest, collectibles, enemies, third-person camera, and HUD.
- No backend or API key required.

This is a full browser game build with procedural 3D assets; future work can add custom character models, animation, sound design, quests, and save progress.
